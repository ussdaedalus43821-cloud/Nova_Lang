# Decision records

Short records of decisions that shape NovaLang and the ecosystem around it, so
the reasoning outlives the conversation that produced it. Format: context,
options, a recommendation, then the decision once the project owner makes it.

Status values:

- **Proposed**: written up with a recommendation; not yet decided. Work that
  depends on it does not start.
- **Accepted**: decided. The "Decision" section says what was chosen and when.
- **Superseded**: replaced by a later record, which is linked.

A decision is changed by writing a new record, not by editing an accepted one.
